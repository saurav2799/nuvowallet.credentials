Verifiable Credentials (VCs), as defined by the W3C standard, enable trusted, tamper-evident digital credentials that can be cryptographically verified anywhere on the web.
They provide a secure and interoperable way to share claims (e.g., identity, qualifications, entitlements) without relying on centralized authorities or exposing unnecessary personal data.

A VC ecosystem involves three key roles:
Issuer: Entity that creates and signs the credential (e.g., government, university, bank).
Holder: Individual or organization that controls the credential (often via a digital wallet).
Verifier: Entity that checks the authenticity of the credential using the issuer’s public key.

VCs are expressed in JSON-LD, signed using cryptographic proofs (e.g., JSON Web Signature or BBS+), and can integrate with Decentralized Identifiers (DIDs) to support privacy-preserving, portable, and self-sovereign identity systems.
